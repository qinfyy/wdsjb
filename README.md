# wd

wd 的协议逆向、资源解析与客户端行为研究工具集。

## 目录

- [UnPacker](UnPacker/README.md)：XMF/BLK、VFS 与 mr0k 资源解包。
- [AbUnPacker](AbUnPacker/README.md)：AssetBundle 资源导出与 JS 源码提取。
- [StaticResParser](StaticResParser/README.md)：策划配置解析为 JSON。
- [WDProtoDumper](WDProtoDumper/README.md)：运行时 Protobuf 定义与命令号导出。
- [JsProtoDumper](JsProtoDumper/README.md)：从 Java Script 恢复 Protobuf 定义。
- [WDSniffer](WDSniffer/README.md)：客户端抓包与协议分析。
- [WDRedirector](WDRedirector/README.md)：客户端流量重定向。
- [DemoServer](DemoServer/README.md)：演示服务端。

依赖、配置和运行方式见各目录 README。仅供技术研究与学习。
